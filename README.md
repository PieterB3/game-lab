# Game Lab

A 5-day hockey game camp for a 7-year-old and a 10-year-old. They write tiny instructions. A rink on the right plays them.

## Start at the office

Double-click `start-lab.bat`, then open Chrome to:

http://127.0.0.1:8765

## What they type

One instruction per line. No braces, no `function`, no quotes.

```
color lime
speed 8
go right
go left
pucks 5
get puck = score
```

Cayden can tap color dots and big buttons. Pieter can type the same words. Both press **PLAY**, then click the rink and use the arrows.

## The week

| Day | Job |
|-----|-----|
| 1 | Color, speed, move every way |
| 2 | Pucks and score |
| 3 | Cones and lives |
| 4 | How to win |
| 5 | Names, look, shoot. Save game and take it home |

**Start over** wipes today only.

Progress saves in Chrome. Same computer Tuesday = they pick up where they stopped.

## Friday take-home

**Save game** downloads `pieter-cayden-game.html`. That file runs by itself.
